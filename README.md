# Matematica din spatele Crypto: Poveste de Liceu și Monitorizare Live
Tabel dinamic în **JavaScript** pentru monitorizarea în timp real a **prețurilor criptomonedelor** — Bitcoin, Ethereum, Solana și alte 27 de active. Include un articol educativ despre **matematica din spatele Bitcoin**: progresii geometrice, probabilități și analiză CVD (Cumulative Volume Delta).

## Demo
🔗 [cryptoral.github.io](https://cryptoral.github.io)

## Despre ce e vorba
- 📊 **Tabel live sortabil** cu prețuri crypto, variații % și actualizare automată
- 📚 **Articol educativ** despre matematica de liceu aplicată în trading
- 🧮 Explicații despre **progresii geometrice**, **probabilități** și **CVD**
- 🎓 Potrivit pentru elevi de liceu care vor să înțeleagă crypto

## Tehnologii folosite
- JavaScript (vanilla, fără framework)
- Fetch API pentru date live
- CSS pentru design responsive
- HTML5 sortabil nativ

## Pentru cine e
- Elevi care se pregătesc pentru **BAC la matematică**
- Începători în **trading crypto**
- Profesori care vor exemple practice de **matematică aplicată**
